# 산화머니 — 개인 작업 요약

고객 소득·자산·지출·기존 대출을 바탕으로 주택 구매력을 계산하고, 예산에 맞는 주택과 대출 상환 계획을 비교하는 팀 프로젝트다.

## 데이터 전처리 및 검증

- 고객 재무·주택 구매·개별 대출 관련 데이터 6개 파일의 구성과 출처를 정리하고 원천 자료와 대조했다.
- pandas로 주택 구매 데이터 42,225행에 고객 ID 기준으로 지역 정보 5개 컬럼을 병합했다. 병합 전후 원본 값과 행 순서가 유지됐으며, 고객 ID 중복과 지역 매칭 실패가 각각 0건임을 확인했다.
- 주택 구매 당시 대출 원금과 현재 잔액을 구분해 집계 기준을 검토했다. 구매에 연결된 대출이 없는 사례는 상환액을 0원으로 처리하고, 적용할 대출이 없는 금리·만기는 결측값으로 유지했다.

## 모델 입력 검토

- 정제한 재무·주택·대출 변수가 팀의 GBM 대출 비율 예측과 kNN 유사 구매자 탐색에 어떻게 사용되는지 코드와 함께 검토했다.
