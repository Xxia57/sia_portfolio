### 유시아 · AI캠퍼스 프로젝트

금융·핀테크 AI 융합가 양성과정에서 진행한 팀 프로젝트입니다. 프로젝트 폴더를 열면 해당 버전의 팀 소스와 문서를 볼 수 있습니다.

| 프로젝트 | 서비스 | 담당 작업 | 자료 |
|---|---|---|---|
| [당신이 잠든 사이에](projects/overnight-briefing) | 야간선물 기반 장전 시가 추정과 보유 종목 뉴스 브리핑 | 시세 데이터 검증, WI26 회귀 결과 재현, 종목·테마 매핑, 뉴스 수집·전처리 | [데모](https://4digit-demo.vercel.app/) |
| [산화머니](projects/myhome-loan) | 고객 재무 기반 주택 구매력 진단과 대출 플랜 추천 | 고객·주택·대출 데이터 전처리, 지역 정보 병합, 대출 예측 모델 입력 검토 | [발표자료](https://github.com/AX-LAB-J/myhome-loan-ai/blob/09ec0e442db811c996ada8a654704c662f1916ab/docs/presentation/service-introduction.pdf) |

두 프로젝트를 한 번에 내려받으려면 다음 명령을 사용합니다.

```sh
git clone --recurse-submodules https://github.com/Xxia57/sia_portfolio.git
```

실행 방법과 데이터 준비는 각 팀 저장소의 README를 참고하세요.
