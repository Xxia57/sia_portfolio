# 유시아 | 데이터 분석 포트폴리오

금융·핀테크 AI 교육과정에서 수행한 팀 프로젝트와 개인 검증 작업을 정리했습니다.

## 당신이 잠든 사이에 | 야간선물 기반 장전 브리핑

야간선물과 과거 시세로 보유 종목의 예상 시가와 참고 범위를 산출하고, 기업·제품 관계 데이터를 바탕으로 보유 종목과 관련된 뉴스를 제공하는 팀 프로젝트입니다.

**개인 기여** — 야간선물 일봉·분봉 조회 범위 및 정합성 검증, WI26 회귀 결과 재현 및 시계열 성능 비교, 종목 테마 매핑, RSS 뉴스 수집·전처리 검토.

[개인 작업 및 검증 결과](projects/overnight-briefing.md) · [팀 GitHub](https://github.com/minseokgeum/ai_campus_main_proj) · [데모](https://4digit-demo.vercel.app/)

## 산화머니 | 주택 구매력 진단·대출 플랜 추천

고객 재무 정보를 바탕으로 감당 가능한 주택 가격을 산정하고, 예산에 맞는 주택과 대출 상환 계획을 비교하는 팀 프로젝트입니다.

**개인 기여** — 고객·주택·대출 자료의 출처와 결합 구조 검토, 주택 구매 데이터 42,225행에 지역 정보 병합 및 검증, 대출 집계·결측 처리 기준과 모델 입력 변수 검토.

[개인 작업 및 검증 결과](projects/myhome-loan.md) · [팀 GitHub](https://github.com/AX-LAB-J/myhome-loan-ai) · [발표자료](https://github.com/AX-LAB-J/myhome-loan-ai/blob/main/docs/presentation/service-introduction.pdf)
