실제 시각 범위는 2025-10-22 18:00~2026-10-22 06:00 KST.

## 결과

- 365일 = 주말 104일 + 정기 휴장 일정과 일치하는 평일 17일 + 특별 야간휴장 2일 + 거래 데이터가 있는 242개 밤.
- KIS 야간 일봉과 분봉의 OHLC 및 거래량이 일치하는 230개 밤: 159,047행.
- 가격은 일치하지만 거래량 차이가 재현되는 12개 밤: 8,438행. 분석 기본 대상에서 제외하고 별도 보존.
- 2026-02-13, 2026-09-23은 공식 증권사 공지로 특별 야간휴장 확인. 수집 실패가 아님.
- 원본 CSV와 수집 진행표는 수정하지 않았음. source_manifest.csv에 원본 파일 SHA-256 기록.

## 해석과 사용 제한

1. VERIFIED는 같은 공급자인 KIS 일봉과의 내부 정합성 통과임. 거래소 독립 검증이나 모든 분의 완전성을 보장하지 않음.
2. 없는 분을 임의로 생성하거나 거래량 0으로 채우지 않았음. 05:50~05:59는 종가 단일가 호가접수 구간으로 별도 취급.
3. API 24시 이상 시간은 실제 익일 시각으로 변환. 원본 날짜/시간 보존. 분봉 라벨이 시작/종료 어느 경계인지 공식 확인 전, 1분 단위 뉴스 선후 인과를 단정하지 말 것.
4. 만기가 가장 가까운 월물 사용, 만기일 저녁부터 다음 월물로 변경. 월물 전환을 넘겨 서로 다른 계약의 가격을 직접 빼지 말 것.
5. 230개 밤만 쓰면 12개 제외에 따른 표본 편향 가능성이 있음. 제외 날짜를 공개하고 사건별 표본 수를 함께 기록.
6. 12개 밤의 거래량 차이 원인은 미해결. 수집 오류로 단정하거나 부족량을 임의 배분하지 않았음. 외부 확인 전까지 데이터 완전성 검증 완료로 표현하지 말 것.
7. 정기 휴장 17일은 공급자 무응답을 휴장으로 간주한 것이 아니라 아래 공식 휴장·휴일 일정과 대조. 신정은 1/2 연초 개장 공지로 확인.
